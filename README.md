# 匹克球分隊

匹克球(Pickleball)分隊小工具:輸入球員名單、設定場地數,一鍵產生對戰組合。

## 功能
- 分隊模式:隨機/實力平衡
- 產生對戰、重洗本輪、復原上一筆
- 記錄每隊勝敗、統計分頁
- 重設今日(歸零勝敗與輪替記憶)/全部重設
- 資料存在瀏覽器裡(localStorage),換裝置不會帶著走

## 檔案
- `匹克球分隊.html` — 主程式,用瀏覽器開啟即可,手機電腦都能用
- `app.fragment.html` — 發佈成網址用的版本(內容片段)
- `artifact_qr.png` — 已發佈網址的 QR code
